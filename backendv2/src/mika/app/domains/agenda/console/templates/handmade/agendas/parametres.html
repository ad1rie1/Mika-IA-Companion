calendar · lire et écrire les agendas

Un seul champ, « sensible » pour Google : il explique l'avertissement « application non validée ».
La créer, pas à pas
  1. Un projet : dans la console Google Cloud (console.cloud.google.com), créer un projet (« Mika », par exemple), avec le compte Google de l'opérateur.
  2. L'API : API et services › Bibliothèque › « Google Calendar API » › Activer.
  3. L'écran de consentement (Google Auth Platform) : type « Externe » ; le nom de l'application, ton adresse ; dans « Accès aux données », le champ …/auth/calendar. Puis, dans « Audience », Publier l'application : en « Test », Google coupe l'accès au bout de 7 jours et seuls les comptes listés entrent. Publiée sans validation, Google prévient « application non validée » : on continue par « Paramètres avancés » (jusqu'à 100 comptes).
  4. Le client : Clients › Créer un client › Type « Application de bureau » ; copier son identifiant et son secret ici, puis Enregistrer.
  5. Brancher : chacun ajoute son Google depuis son espace (Paramètres › Agendas › Google). Après le consentement, Google renvoie vers http://127.0.0.1/…?code=… : on colle cette adresse. Avec un client « Application Web » et une adresse HTTPS, le retour est direct.

{{ g.title }}

{% if g.title == "Synchronisation" %}

Un processus relit chaque compte à son rythme ; une écriture part tout de suite chez le fournisseur, puis l'agenda se relit. Une panne se voit sur le compte et dans Système › Santé générale. Le système n'a rien à relire : il est sur ce serveur.

{% elif g.title == "Rappels" %}

Le délai qu'elle propose d'office à un agenda dont la personne n'a pas choisi le sien ; chacun le change ensuite, agenda par agenda, dans son espace. Un abonnement iCal n'a pas de rappel. Un rappel est une initiative : l'arbitre peut le retenir.

{% elif g.title == "Invitations" %}

Une invitation qui attend sa réponse : elle prépare la réponse, qui ne part qu'avec un accord.

{% elif g.title == "Accords" %}

Combien de temps vaut la carte d'accord du chat ; la proposition, elle, attend jusqu'à la décision ou au début du rendez-vous.
