# Mika's room — sources

`room.blend` is the source of `public/models/room.glb`, the room loaded by
`src/scene/RoomModel.ts` (with `src/scene/ProceduralRoom.ts` as the fallback when
the GLB is missing or unreadable).

## Rebuilding

The whole room is generated by the scripts in `blender/` (Blender 5.2, Python
console), so a change is a script edit + one run:

```python
BLENDER_SCRIPTS_DIR = "/path/to/frontend/Web/assets-src/blender"
SAMPLES = 128                      # AO bake samples
exec(open(BLENDER_SCRIPTS_DIR + "/run_final.py").read())
```

`run_final.py` rebuilds every object (`build_all.py`), applies modifiers, makes the
second UV map (`AO`, smart-project + packed into one shared space), bakes ambient
occlusion with Cycles **on the CPU** (the CUDA bake writes a black image on this
machine) into `textures/room_ao.png` (2048², one atlas), wires it as the glTF
occlusion texture on UV 2, exports `public/models/room.glb` and saves `room.blend`.
The movable desk chair is baked in a second pass so its contact shadow is not
burnt into the floor. `textures/` holds every texture the scripts use;
`gen_textures.py` regenerates them (it expects the Poly Haven downloads listed
below in `blender/ph/<name>_diff_1k.jpg`).

Coordinates in the scripts are three.js coordinates (`V(X, Y, Z)` → Blender
`(X, -Z, Y)`); the glTF exporter's +Y-up conversion brings them back unchanged.

## Names the code relies on

| Object / material | Used for |
| --- | --- |
| `Window_Sky` | card behind the window opening; gets the sky shader (`SkyMaterial.ts`) |
| `Monitor_Screen` / `M_MonitorScreen` | screen flicker |
| `Clock_HourHand`, `Clock_MinuteHand` | set to the real time (rotate about local Z) |
| `LightAnchor_DeskLamp`, `_BedLamp`, `_Ceiling`, `_Monitor`, `_Window` | empties; Environment puts its point lights there |
| `DeskChair` | one object (hoodie included), origin on the floor under the seat centre, yaw kept on the node — the locomotion code slides it |
| any other emissive material (`M_DeskLampGlow`, `M_BedLampShade`, `M_BedLampBulb`, `M_CeilingLampShade`, `M_CeilingLampBulb`, `M_StarGlow`, `M_MoonLamp`, `M_NeonSign`, `M_CandleFlame`) | scaled by the sleep-phase light multiplier; their strengths sit above the bloom threshold on purpose |

Fairy lights, ceiling LED strips, dust, the floor light patch and all lights are
built in `src/scene/Environment.ts`, not in the GLB (they are animated).
